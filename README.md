# 🐾 Sistema de Adoção de Animais
📖 Descrição do Projeto

O Sistema de Adoção de Animais é uma plataforma web desenvolvida para facilitar o processo de adoção responsável de cães e gatos. O site permite que usuários visualizem animais disponíveis para adoção por meio de cards informativos, contendo fotos, características e informações relevantes sobre cada animal.

⚙️ Funcionalidades

Exibição de animais disponíveis para adoção em formato de cards.
Visualização de informações detalhadas dos animais.
Cadastro de interessados na adoção.
Formulário de contato para adoção.
Pesquisa e filtragem de animais.
Interface responsiva para dispositivos móveis e computadores.
Armazenamento e gerenciamento dos dados dos animais cadastrados.

🎯 Motivação

Milhares de animais são abandonados todos os anos e enfrentam dificuldades para encontrar um lar seguro. Instituições como a Ardap não tem uma aplicação web para facilitar processos de adoção dos animais.
